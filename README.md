# Автоматизация Wildberries API v3: Синхронизация остатков

Отказоустойчивый скрипт на **Python** для автоматического пакетного обновления остатков товаров на маркетплейсе **Wildberries** с использованием актуального **API v3** (Suppliers Portal).

##  Ключевой функционал системы
* **Пакетная обработка (Batching):** Данные из локального склада делятся на пакеты по 100 позиций для оптимизации сетевой нагрузки.
* **Защита от блокировок (Rate Limit Shield):** Встроенные задержки (`time.sleep`) и кастомная стратегия повторных запросов (`urllib3.util.Retry`) защищают аккаунт от ошибок *429 Too Many Requests*.
* **Валидация данных через Pandas:** Быстрое считывание, очистка от дубликатов и проверка структуры файлов Excel/CSV без ресурсоемких циклов `for`.
* **Автономность:** Использование планировщика `APScheduler` для круглосуточного запуска скрипта по заданному интервалу (каждые 15 минут).
* **Сквозное логирование:** Запись каждого шага, сетевых статус-кодов и критических ошибок в изолированный файл `wb_sync.log`.

##  Безопасность и архитектура
Проект разработан с соблюдением стандартов коммерческой безопасности:
* Все конфиденциальные доступы (**API-токены**, **ID складов**) полностью изолированы от кодовой базы.
* Данные считываются динамически из переменных окружения Windows/Linux через `os.getenv()`.
